# 过面 · 隐私政策

> 文档版本 1.3 · 落款日期 2026-08-13 · 对应产品版本 0.5.x
> （本档六条声明自 V1.6 起由 `test/privacy.test.mjs` 源码机检在守：禁用 API 黑名单、
> 网络调用点白名单、localStorage 触点白名单——新增网络调用不改本档与白名单即测试红。）
> 路径基准：本仓根（`E:\cursor-work\模拟面试\模拟面试官系统\`）。
> 写作纪律：以下每一条都对着当前实现逐条核过（括号内为代码背书位置），不写做不到的承诺；
> 「当前版本」限定语是有意的——未来版本若引入新数据流，本文必须先改再发。

「过面」是一个本地优先的 AI 模拟面试工具。关于你的数据，事实很简单：**我们收不到，因为压根没有上传的路。** 下面逐条说清。

## 1. 你的面试内容只存在你自己的设备上

你贴入的岗位 JD、简历、每一条回答、生成的评分与报告、练习台账，全部只保存在你浏览器的
localStorage 里（键前缀 `guomian:`），不上传任何服务器。解析、出题、评分、报告生成全部在你
的浏览器本地完成——断网也能完整跑完一场面试，这是产品的结构性设计而不是口头承诺。
（代码背书：`app/app.js` 经 `createStore(localStorage)` 落本机；引擎层 `src/engine/*`、`src/report`
均为纯本地计算，无任何网络调用。）

## 2. 服务端不接收业务数据

本地开发用的服务端只做两件事：托管静态文件、回应健康检查 `GET /health`。它没有任何接收
数据的接口——非 GET/HEAD 请求一律返回 405。公网部署形态是纯静态托管（`npm run build` 产出
的 `dist/` 目录），托管商仅有行业标准的访问日志（IP、访问时间、请求路径等），我们不在其上
叠加任何自己的收集。
（代码背书：`server/index.js` 白名单静态托管＋405 拦截，无 POST 业务接口；机检：
`test/server.test.mjs` 断言非 GET/HEAD 返回 405。）

## 3. 可选的「AI 增强」：数据去向由你决定

默认（不填任何配置）产品是纯本地模式，上述第 1 条完整成立。

如果你在「AI 增强（可选）」面板里自行填入第三方 API 端点（baseURL）、密钥（apiKey）与模型名，
那么在面试追问润色环节，**面试问答的相关内容会被发送到你自己指定的那个第三方端点**——发给谁、
发到哪，完全由你填的地址决定，我们不设默认端点、不做中转。该第三方如何处理这些数据，以它的
服务条款与隐私政策为准，请在填入前自行确认。

你的 apiKey 只保存在页面内存变量里，关闭或刷新页面即消失；我们不经手、不存储、不回传。
（代码背书：`src/llm/index.mjs` 是全部源码中唯一**主动发起对外业务请求**的调用点——另有 `sw.js`
两处 fetch 属 Service Worker 对同源静态资产的缓存透传，不携带任何业务数据；请求只发往 `config.baseURL`
拼出的端点；`app/app.js` 中 apiKey 为函数局部量，从不写入 storage；面板旁明示「不会保存」。）

## 4. 数据删除：清掉即彻底消失

所有数据都在你的设备上，删除方式就是清除浏览器的站点数据（浏览器设置 → 站点数据/Cookie 与
网站数据 → 清除本站）。清除后数据即彻底消失——我们无从恢复，也无从知晓你清除过，因为我们
从未持有过副本。

## 5. 当前版本：无 Cookie、无埋点、无第三方统计

当前版本不设置任何 Cookie，不接入任何统计/分析/广告 SDK，不做任何行为埋点。全部源码中
不存在第三方统计代码。Service Worker 缓存的只是应用自身的静态资产（页面、样式、引擎模块），
不缓存、不上报你的任何内容数据。
（代码背书：全仓检索无 `document.cookie`、无统计 SDK、无 `sendBeacon`；`sw.js` 只缓存同源
静态 GET 且明确排除 `/health`。）

另：应用内「隐私承诺 → 查看完整文本」会请求本站静态托管的本政策文本自身（同源 GET，
无任何业务数据）——这是 `app/app.js` 唯一的网络调用点，已入 `test/privacy.test.mjs`
的 FETCH_WHITELIST 机检。

## 6. 体验码与模拟购买记录同样只在本地

兑换体验码、模拟购买到账的权益（解锁券/会员状态）与兑换去重记录，都记在你本机的
localStorage 里，随第 4 条的清除一并消失。当前版本没有真实支付，不涉及任何支付信息收集；
未来接入真实支付时，本政策将先行更新并明确支付环节引入的第三方。
（代码背书：`src/monetize/index.mjs` 全部权益操作走注入的本地 store，无网络调用。）

## 7. 可选的语音作答：音频经你的浏览器厂商识别，我们不碰音频

语音作答默认关闭，只有你主动点击作答区的麦克风按钮才会启动；浏览器不支持时该按钮
根本不出现，纯文字路径完整可用——不使用语音不影响任何功能。

音频的流向要如实说清：语音识别用的是**浏览器内置的识别服务**（Web Speech API），
你的语音通常会被发送到浏览器厂商（如 Google、Apple）的云端语音服务做识别——这一段
发生在浏览器内部，**本产品的代码不接触任何音频字节**，不录制、不上传、不存储任何音频，
我们只接收浏览器识别完成后返回的文字。浏览器厂商如何处理这段音频，以其隐私政策为准。

识别出的文字会填进作答框，你可以修改后再提交；它与手打文字同等对待——按第 1 条只存
你本机的 localStorage，绝不上传。首次使用前应用会弹出说明并请你确认，你的确认选择记在
本机（localStorage 键 `guomian:voice-consent`），同样随第 4 条的清除一并消失。
（代码背书：`app/app.js` 语音模块只调用 `SpeechRecognition` 接口、只消费其返回的
识别文本，全仓无 `getUserMedia`/`MediaRecorder` 等任何音频采集调用，无新增网络调用点——
`test/privacy.test.mjs` 的 fetch 白名单未因本功能变化。）

---

## 一句话总结

不填 AI 增强，你的文字数据不出你的设备；填了 AI 增强，问答内容只发给你自己指定的第三方；
用语音作答，音频只经你的浏览器厂商识别（见第 7 条）。任何情况下我们都收集不到你的任何数据。

对本政策有疑问，或发现实现与本文不符，欢迎以任何渠道向我们指出——「实现与声明一致」在
本项目里是有测试机检守着的工程纪律（见 `docs/架构契约.md` 产品语义三条硬承诺）。
